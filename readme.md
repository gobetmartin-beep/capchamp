# Getting Started

# Steps to reproduce

1. Clone the repo from Github inside BAS either by **UI** or type **git clone https://github.com/gobetmartin-beep/capchamp.git** in terminal
2. Checkout to branch **domain.model** either by UI or type **git checkout domain.model** in terminal
3. Make sure your terminal pointing to your projet. If no, go to the project you have created using **cd <project name>**.
4. Type cds watch inside terminal
5. Run the browser or go to your file in test.http and do the testing
